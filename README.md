# 💊 MedLens - Landing Page

Repositorio oficial del sitio web promocional de **MedLens**, una aplicación diseñada para gestionar recordatorios de medicamentos y eventos de forma sencilla, eficiente y operando localmente en el dispositivo.

Este proyecto está estructurado para presentar las características principales de la aplicación, detallar su funcionamiento y alojar de manera accesible los documentos legales requeridos.

## 🛠️ Tecnologías utilizadas
* **React (JSX):** Arquitectura basada en componentes para la interfaz de usuario.
* **Tailwind CSS:** Estilizado ágil, moderno y 100% responsive.
* **React Router:** Gestión de rutas para una navegación fluida entre la página principal (Landing), Políticas de Privacidad y Términos de Uso.
